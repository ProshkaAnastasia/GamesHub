# Изображения для «Криптида»

Все 19 изображений из этого набора подключены к игре из `public/cryptid/`.
SVG отвечает за форму клеток, границы территорий, номера и цвета игроков;
текстуры местности, значки, деревянные маркеры и оформление берутся из PNG.
Ниже сохранены промпты для воспроизведения или обновления набора:
16 основных файлов и 3 изображения оформления.
Не нужно генерировать целую карту: её расположение меняется каждую партию.

Общий стиль: авторская иллюстрированная карта загадочной североамериканской
экспедиции, вид строго сверху, мягкая гуашь и тонкая бумажная фактура, приглушённые
природные цвета, ясные силуэты. Без копирования иллюстраций настольного издания.
Без надписей, букв, цифр, логотипов, водяных знаков и встроенных игровых маркеров.
Все элементы должны оставаться различимыми в размере 40–60 пикселей.

## Передача файлов

Сохранять PNG с точными именами в `public/cryptid/`. Не добавлять цифры клеток,
номера игроков или маркеры на изображения местности — они меняются во время игры.
Текущие имена файлов уже соответствуют этому списку. PNG используются без
изменения исходных изображений. Игра обрезает текстуры по форме гексов, окрашивает
серые деревянные маркеры в цвета игроков и добавляет номера поверх них.
Для местности нет нужды рисовать отдельную картинку на каждую клетку.
