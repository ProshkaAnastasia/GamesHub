Индекс содержит 95 дверей и 75 сокровищ. Для всех 170 записей проверено наличие соответствующего файла в дереве репозитория. Тексты эффектов находятся на изображениях, а JSON содержит только названия и пути. Проверена читаемость нескольких образцов; построчная проверка всех карт ещё не выполнена.

Это не готовая актуальная колода: встречаются старые переводы, варианты и дополнительные карты. Например, `gold036.gif` и `gold068.gif` имеют символ набора; `gold068.gif` — Q-кубик. Нельзя просто использовать все 170 записей или без сверки удалить две произвольные карты.

Визуально проверены: `monster014.gif` («Смена класса»), `gold039.gif` (бензопила), `gold036.gif`, `gold068.gif`, `gold074.gif` (читерский кубик), `gold075.gif` (вариант наколенников), `gold001.gif`.

## Таблица, присланная пользователем

[Базовый Манчкин.xlsx](https://disk.yandex.com/i/u_joXf51bweJn) содержит 74 строки дверей и 72 строки сокровищ, без заголовков. При буквальном учёте пометок количества получается 90 дверей и 74 сокровища.

Выявлено:

- Отсутствует отдельная строка «Смена класса». Её эффект ошибочно указан в строке «Потеряй класс».
- У хафлинга не указаны три экземпляра: при исправлении количества добавляются две двери.
- Строка эльфа повреждена: название «ю», количество не указано. Эффект соответствует эльфу; при восстановлении трёх экземпляров добавляются ещё две двери.
- Эти исправления дают 95 дверей. Это объясняет расхождение количества, но не доказывает правильность каждого эффекта.
- У волшебной лампы указаны два экземпляра; официальный актуальный список содержит один. Исправление даёт 73 сокровища.
- Пропущен бонус бензопилы: изображение подтверждает +3, две руки, большая, цена 600.
- У остроконечной шляпы в таблице отсутствует ограничение класса; требуется сверка.

Таким образом, разница 164/168 — не четыре отсутствующих уникальных карты. Есть пропущенные повторы, лишний повтор и одна отсутствующая строка.

## Что ещё требуется перед реализацией

Сопоставить каждое название с официальным английским списком, проверить изображения и применить актуальные исправления. Для каждой карты хранить ссылку на источник, количество и краткое описание механики своими словами. Не считать наличие 168 записей доказательством полноты и правильности эффектов.
