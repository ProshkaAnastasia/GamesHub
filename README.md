# Декодер — онлайн-версия

Веб-версия настольной игры «Декодер» (Decrypto). Две команды по 2–4 игрока,
каждая передаёт свои секретные коды через ассоциации, пытаясь понять свои
подсказки и перехватить чужие. Игроки заходят каждый со своего устройства
по ссылке-приглашению — сервер и вся логика работают в реальном времени
через WebSocket (Socket.IO).

## Локальный запуск в Docker

```bash
cp .env.example .env
mkdir -p data
# На Linux: sudo chown -R 1000:1000 data && chmod 700 data
docker compose up -d --build
```

Откройте http://localhost:3000. Порт по умолчанию доступен только локально.
Для публичного сервера используйте HTTPS-прокси: настройка, права на данные,
доступ из локальной сети и описание переменных — в [SECURITY.md](SECURITY.md).
Пример конфигурации Caddy — [Caddyfile.example](Caddyfile.example).

Новых участников приглашайте кнопкой «Копировать ссылку»: по умолчанию
нужна ссылка с секретным токеном, одного кода комнаты недостаточно.

### Остановить / обновить

```bash
docker compose down
docker compose up -d --build   # пересборка после изменений в коде
```

## Как найти игроков

Введите имя, выберите игру и нажмите «Найти игру». Сервер случайно выберет
публичную комнату ожидания этой игры или создаст новую. Хоста нет: после набора
минимального состава начнётся 15-секундный отсчёт. Для Decoder нужны 3–8 игроков,
для Ticket to Ride — 2–5. Если игроков становится меньше минимума, отсчёт отменяется.

Для игры с друзьями нажмите «Создать приватную комнату». Хост выбирает игру
внутри комнаты, копирует приглашение и запускает партию. Комната не участвует
в подборе; войти по одному номеру нельзя. Регистрация не требуется.

Выход доступен всегда. Уход участника завершает активную партию; при обрыве
связи время возвращения не ограничено. На главной доступна кнопка «Вернуться в игру».
Если участник офлайн, оставшиеся могут завершить партию вручную. После публичной
партии можно сразу искать новую.

## Как играть

1. Один игрок создаёт комнату и получает четырёхсимвольный код и ссылку-приглашение.
2. Остальные открывают ссылку-приглашение и вводят имя.
3. В лобби собираются 3–8 игроков; при старте сервер случайно распределяет их по командам.
4. Хост нажимает «Начать игру».
5. Каждый раунд в команде по очереди меняется шифровальщик — он видит
   секретный числовой код (например 2‑4‑1) и 4 слова своей команды.
   Он придумывает по одной ассоциации на каждую цифру, не называя сами слова.
6. Все подсказки становятся видны обеим командам.
7. Своя команда пытается разгадать порядок цифр по подсказкам;
   команда соперника пытается перехватить чужой код.
8. Два неверных «своих» расчёта — поражение; два перехвата соперником —
   тоже поражение. Побеждает другая команда.

### Режим на троих

Достаточно собрать в лобби трёх игроков. При каждом старте сервер случайно
назначает игрока А, игрока Б и общего игрока. Обе команды получают по четыре слова.
В нечётных раундах общий игрок шифрует для А и разгадывает код Б;
в чётных — шифрует для Б и разгадывает код А. Сначала он видит слова команды, для которой шифрует, затем — слова команды,
код которой разгадывает,
поэтому не участвует в перехватах и тай-брейке: эти ответы дают только
игроки А и Б. Счёт и условия окончания партии такие же, как в обычном режиме.

После подтверждения всех ответов раскрываются настоящие коды обеих команд,
даже если ни своя расшифровка, ни перехват не удались. Коды остаются в истории раундов.

## Технические детали

- Комнаты хранятся в памяти и сохраняются в JSON-файлы в `server/data/rooms`.
  В Docker эта папка находится в подключённой директории `data`.
- Восстановление игрока защищено подписанной HttpOnly cookie. Сессия и ключ
  подписи переживают перезапуск контейнера при сохранении `data`.
- Один процесс Node.js обрабатывает все комнаты. Лимиты событий и ресурсов
  рассчитаны на небольшой сервис; настройки находятся в `.env.example`.
- Проверки: `cd server`, затем `npm ci` и `npm test`.

## Codenames

Отдельный модуль `server/games/codenames`, клиент — `public/codenames.js`.
Доступен в публичном подборе и приватных комнатах для 2–8 игроков онлайн.
При старте для 2–3 игроков автоматически выбирается «Дуэт», для 4–8 — обычная
версия. Участники распределяются случайно при каждом старте. В обычной версии
назначается по одному капитану на команду.

Поле 5×5: 9 агентов начинающей команды, 8 соперника, 7 мирных жителей и убийца.
Секретная карта передаётся только капитанам; агенты и зрители видят только
открытые карточки. Капитан даёт слово и число, агенты открывают карточки
с подтверждением. Реализованы лимит «число + 1», подсказки 0 и ∞, завершение
хода, победа по агентам и поражение от убийцы. Семантические ограничения
подсказок (например, однокоренные слова) контролируются участниками;
совпадение с неоткрытым словом поля запрещается сервером.

В «Дуэте» все играют сообща: нужно найти 15 агентов за 9 ходов. У каждой
стороны свой секретный ключ (9 агентов, 3 убийцы); подсказки дают по очереди,
а догадки проверяются по ключу партнёра. При трёх игроках на одной стороне
двое, на другой — один. Число в подсказке не ограничивает количество попыток.
Мирный житель отмечается отдельно для каждой стороны. После девятого хода
остаётся последний шанс: угадывать могут обе стороны без новых подсказок,
любая ошибка завершает миссию поражением. Ключ партнёра раскрывается только
после завершения партии, оба ключа сохраняются в архиве.
[Правила «Дуэта»](https://filemanager.czechgames.com/storage/files/codenames-duet/rules/codenames-duet-rules-en.pdf).

Используется существующий русский словарь проекта, не официальный набор карточек.
Сохранение, возвращение, завершение при офлайн-игроке и архив работают через общую
инфраструктуру комнат. [Правила издателя](https://czechgames.com/files/rules/codenames-rules-en.pdf).

Изображения накладок Codenames находятся в `public/codenames/cards/` (PNG).
Сопоставление файлов с командами и типами карточек задано в `cardImages` в
`public/codenames.js`. Картинка показывается только на открытой карточке;
слово остаётся поверх неё. Анимация укладывания срабатывает при новом открытии,
не повторяется при чате и перезагрузке, учитывает prefers-reduced-motion.

## Каркассон

Отдельный модуль `server/games/carcassonne`, клиент `public/carcassonne.js`,
общие геометрия и каталог плиток — `public/carcassonne-tiles.js`.
Базовая игра для 2–5 игроков: 72 плитки, 7 миплов на игрока, дороги, города,
монастыри и поля. Без реки, аббата и дополнений. Иллюстрации плиток находятся в `public/carkasson/cards/A.png`–`X.png`.
Все изображения квадратные; поворот и миплы накладываются отдельно.

В свой ход поверните текущую плитку и выберите подсвеченное место на поле.
После размещения выберите объект новой плитки для мипла либо завершите ход
без мипла. Кнопка «?» содержит правила; ползунок меняет масштаб поля,
большое поле прокручивается. Начисления очков видны под полем.

Совпадение всех краёв, занятость соединённых объектов, большинство миплов,
завершение и итоговый подсчёт проверяются сервером. Фермеры дают по 3 очка
за каждый завершённый город у поля. Невозможная для размещения плитка
сбрасывается автоматически. Будущая колода не передаётся клиенту.
Работают общий подбор, приватные комнаты, зрители, возвращение и архив.
[Правила базовой игры и дополнения к правилам](https://www.zmangames.com/game/carcassonne/).
