# Декодер — онлайн-версия

Веб-версия настольной игры «Декодер» (Decrypto). Две команды по 2–4 игрока,
каждая передаёт свои секретные коды через ассоциации, пытаясь понять свои
подсказки и перехватить чужие. Игроки заходят каждый со своего устройства
по ссылке и коду комнаты — сервер и вся логика работают в реальном времени
через WebSocket (Socket.IO).

## Быстрый запуск на сервере (только IP, без домена)

Понадобится Docker и Docker Compose на сервере.

```bash
# 1. Скопируйте папку проекта на сервер, например через scp/git, затем:
cd decoder-game

# 2. Соберите и запустите контейнер
docker compose up -d --build

# 3. Откройте в браузере (замените на реальный IP сервера)
http://ВАШ_IP:3000
```

Игроки заходят на `http://ВАШ_IP:3000` с любого устройства (телефон,
ноутбук) — домен не нужен, достаточно IP-адреса и порта.

### Если порт 3000 закрыт файрволом

```bash
# Ubuntu/Debian с ufw
sudo ufw allow 3000/tcp
```

Либо смените порт в `docker-compose.yml` (например `"80:3000"`, чтобы
играть без указания порта в адресе — тогда достаточно `http://ВАШ_IP`).

### Остановить / обновить

```bash
docker compose down
docker compose up -d --build   # пересборка после изменений в коде
```

## Как играть

1. Один игрок создаёт комнату и получает 4-значный код.
2. Остальные заходят на тот же адрес и вводят этот код.
3. В лобби собираются 3–8 игроков; при старте сервер случайно распределяет их по командам.
4. Хост нажимает «Начать игру».
5. Каждый раунд в команде по очереди меняется шифровальщик — он видит
   секретный числовой код (например 2‑4‑1) и 4 слова своей команды.
   Он придумывает по одной ассоциации на каждую цифру, не называя сами слова.
6. Все подсказки становятся видны обеим командам.
7. Своя команда пытается разгадать порядок цифр по подсказкам;
   команда соперника пытается перехватить чужой код.
8. Два неверных «своих» расчёта — поражение; два перехвата соперником —
   тоже поражение. Побеждает другая команда.

### Режим на троих

Достаточно собрать в лобби трёх игроков. При каждом старте сервер случайно
назначает игрока А, игрока Б и общего игрока. Обе команды получают по четыре слова.
В нечётных раундах общий игрок шифрует для А и разгадывает код Б;
в чётных — шифрует для Б и разгадывает код А. Он видит оба набора слов,
поэтому не участвует в перехватах и тай-брейке: эти ответы дают только
игроки А и Б. Счёт и условия окончания партии такие же, как в обычном режиме.

## Технические детали

- Состояние комнат хранится в памяти процесса — при перезапуске контейнера
  все текущие игры сбрасываются (для семейного/дружеского использования
  это нормально; для более надёжного варианта потребуется внешнее
  хранилище, например Redis).
- Один процесс Node.js обрабатывает все комнаты — этого достаточно для
  небольшого сервера на несколько одновременных игр.
- Переподключение при обрыве соединения не восстанавливает прежнего игрока
  (нужно будет зайти заново по коду комнаты).
